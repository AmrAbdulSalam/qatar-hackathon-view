# Coding4Integrity Hackathon — Amr Abdul Salam

A small static site about my participation in the **Coding4Integrity** Arab Youth Anti-Corruption
Hackathon (Doha, Qatar, Jul–Sep 2023, organized by Microsoft, UNODC, and ACTA), and the project my
team (**POJEM Mashup**) built: **اطمئن** (*Itmi'nan* — "Rest Assured"), an Azure-based AI chatbot
for anonymous, secure corruption reporting.

## Structure

- `index.html` — page content
- `style.css` — styles
- `script.js` — mobile nav toggle

## Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploying to GitHub Pages

1. Push this repo to GitHub.
2. In the repo settings, go to **Pages**.
3. Set the source to the `main` branch, root folder.
4. The site will be published at `https://<your-username>.github.io/<repo-name>/`.
